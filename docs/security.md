# 🔐 Cloud Security

Production guidance:

- Federated or short-lived credentials
- Workload identity
- Least-privilege IAM/RBAC
- Private networking where appropriate
- Encryption at rest and in transit
- Secrets managers
- Centralized audit logging
- Policy-as-code
- Vulnerability scanning
- Separate state and credentials by environment
